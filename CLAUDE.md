# Evolution Sim Project: rules for the AI coding agent

A browser-based artificial-life simulation. Simple organisms evolve in a changing world. Roles like predator, herbivore and scavenger **emerge** from mutation plus one rule: everything costs energy. It is not a game and not visually polished: clarity and data matter more than looks.

The owner does not write code. Changes must be explainable in plain English and checkable by watching the sim and its graphs.

Planning notes live in the owner's Obsidian vault: `Projects/Evolution Sim Project/` (`01 - Overview`, `02 - Roadmap`). The roadmap defines the phases and each phase's "Done when" criteria.

## Hard rules

1. `packages/sim-core` must never use browser APIs (no `window`, `document`, DOM, canvas) or Node-only imports. It must run unchanged in a browser, a Web Worker and Node.
2. Never use `Math.random()`, `Date.now()`, `new Date()` or `performance.now()` in simulation logic. All randomness comes from the seeded `Rng` in `sim-core`.
   In `sim-core`, also avoid `Math.sin/cos/log/exp/pow/atan2` and the `**` operator: browsers may round them differently in the last digit, so the same seed would play out differently in Chrome, Safari and Firefox. Use only exact operations (`+ - * /`, `Math.sqrt`, `Math.floor`, `Math.fround`, `Math.min/max/abs`). For a power like `size^0.75`, build it from `sqrt`. A guardrail test enforces this.
3. The simulation advances in fixed **ticks**, never real time. Rendering speed must never change simulation results.
4. All tuning numbers (costs, rates, thresholds, caps) live in a single config object. No magic numbers in logic.
5. Same seed + same config must give exactly the same history. Do not iterate over unordered structures in a way that changes results, and do not depend on timing.
6. Energy is the universal currency. Every trait costs energy, and every energy gain or loss goes through the energy ledger (`Simulation.ledger`). Never create or destroy energy outside defined sources (plants regrowing) and sinks (upkeep, movement, sensing). The energy conservation test and the matter conservation test in `simulation.test.ts` must keep passing; if you add a new energy flow, add it to the ledger and to that test, and if you add a new place matter can sit, add it to `matterAudit()`.
7. There are no hard-coded roles. No `Predator` or `Herbivore` classes. Behavior must come from genes and environment.
8. Run `npm test` and `npm run typecheck` before every commit. Never commit with failing tests.
9. Prefer simple, readable code over clever code. Add a short comment explaining *why* for anything non-obvious.

## Working style

- Work **one roadmap phase at a time**, each on its own git branch (`phase-1-minimal-world`, etc.). Merge to `main` when the phase's "Done when" items are met.
- At the start of a phase, read this file and the phase's goals, then **propose a plan before writing code**.
- Explain changes in plain English for a non-programmer. Say what changed in the sim's behavior, not just in the code.
- Commit small and often so any change can be rolled back.
- Describe how to *see* each result (which chart, which overlay, which seed).
- Add tests as guardrails: determinism, energy conservation, golden seeds, snapshot round-trips. Keep growing them.
- If a result looks too good (something absurdly successful), check the energy ledger for an exploit before celebrating.
- Write a devlog entry in `docs/devlog/` at the end of each phase: what was built, what emerged, what broke, one image. Also append the same entry to the owner's Obsidian note `Projects/Evolution Sim Project/03 - Devlog`, and tick the roadmap checkboxes in `02 - Roadmap` as each item is verified working (only tick what you actually verified).
- Balancing is done with evidence: run many seeds (`npm run sim -- --seeds 1-12 ...`) and look at the spread, not one run. Report honestly when a "Done when" item is only partly met.
- Never push, publish or deploy without the owner's go-ahead.

## Layout

```
packages/sim-core/   the simulation: pure logic, no UI, no browser or Node APIs
apps/viewer/         browser app: world view, charts, inspector (Vite + TypeScript)
apps/runner/         Node CLI for headless batch experiments (tsx)
tests/               repo-wide guardrail tests (e.g. forbidden APIs in sim-core)
configs/             preset worlds as JSON (each is a named set of config changes; the viewer lists them)
experiments/         saved results (raw output is git-ignored)
docs/devlog/         one entry per phase
```

## Commands

```
npm install        install everything
npm test           run all tests (vitest)
npm run typecheck  type-check every workspace
npm run dev        start the viewer locally
npm run build      production build of the viewer
npm run sim -- --seed 42 --ticks 100000     one headless run (CSV of stats + trait histograms)
npm run sim -- --seeds 1-12 --ticks 50000   many seeds in parallel, then compare how they differ
npm run sim -- --config configs/costly-movement.json --seed 3   run a preset world (--set name=value tweaks any setting)
npm run bench      how fast is the simulation?
npm run bench -w apps/runner -- --sizes 512,1024 --config configs/brains-evolvable.json --set foodRegrowPerTick=0.02   benchmark a big brainy world
npm run sim -- --seed 5 --ticks 3000 --save w.evosnap     save the finished world
npm run sim -- --load w.evosnap --ticks 2000               carry on from a saved world (add --branch-seed N for a different random future)
npm run gif -- --seed 12 --ticks 60000   render a time-lapse GIF of a run
npm run exp -- check|estimate|run|status experiments/<name>   experiments from a file (Phase 9): saves progress, resumes, estimates cost
npm run exp -- cloud launch experiments/<name> [--confirm]     run it on one on-demand AWS machine (never without the owner's yes; see infra/aws/README.md)
npm run exp -- cloud status | cloud fetch experiments/<name> | cloud stop
```

## Tech notes

- TypeScript everywhere, npm workspaces. `sim-core` is consumed as TypeScript source (no build step).
- Simulation data uses typed arrays (struct-of-arrays) for speed; spatial queries use a spatial hash grid.
- Each organism has a genome (twenty-six genes: thirteen from earlier phases, five for multicellularity, two social ones, fat, torpor, palate and two stress and calm responses and generosity, see below; the first thirteen are each 0 to 1: size, speed, sense range, metabolism, color, mutation rate, diet, attack, armor, stamina, thermal, lifespan, litter). The last four are optional: stamina needs `sprintFatigue`, thermal needs a climate with `thermalCostCoeff` above 0, lifespan needs `agingCoeff` above 0 and litter needs `litterMax` above 1. A gene that is not in use is neither mutated nor fingerprinted (`activeGene`), so older worlds stay bit-for-bit identical (`CORE_GENE_COUNT`). The species tracker and mate compatibility look only at the active genes. Traits and per-tick costs are worked out from the genes once, at birth, and cached; the per-tick loop only does arithmetic on cached numbers. Gene order and the gene-to-trait mapping live in `genome.ts`.
- Energy goes one way (sun to plants to eaters to heat) and matter goes in a circle (soil, plants, detritus, soil; soil, bodies, corpses, detritus, soil). Plants need nutrient to grow, and a newborn's body is built from the soil it is born on.
- Predation is physics, not a role: any organism whose attack trait is above `attackThreshold` tries to kill the nearest prey in reach, with odds from attack power against defense. There is no Predator class and nothing is hard-coded about who eats whom.
- Brains are optional (`brainMode` 0 = none, the control; 1 = fixed layout; 2 = evolvable layout). They live in `brain.ts` (network and mutation) and `Simulation.think()`. All brain-world extras are off by default so earlier worlds do not change: `brainAppetiteSenses`, `sprintFatigue` (stamina), `killOwnershipTicks` (first claim on a kill), and `scentDeposit` (scent trails, laid whenever brains are on; set 0 to disable). Adding a brain input shifts node numbers and so changes brain-world golden fingerprints; brains-off goldens must never change.
- Species and the family tree live in `species.ts` and only WATCH the world: no random numbers, nothing in the world fingerprint, so they can never change what happens. A species is a group centered on its members' average genes (color and mutation rate ignored); a candidate needs `speciesMinMembers` members for `speciesProbation` ticks to count. Keep it observation-only: if species ever fed back into behavior it would be a hard-coded role.
- The dynamic world is all optional and off by default: `terrainMode` (biomes from noise, water is a hard barrier; `terrain.ts`), `climateMode` (temperature field, day/night, seasons, drift; `climate.ts`) and `catastropheKind` (ice age, drought, meteor). Terrain uses its own random stream derived from the seed. Per-tick climate arrays are recomputed from the tick, so they are not saved. A meteor must route what it destroys to a sink (plant matter to detritus, plant energy to `decayLoss`) so the conservation tests still pass.
- Phase 7 features, all off by default (check the goldens after touching any of them): aging (`agingCoeff`: extra upkeep past a prime, plus a repair cost for a long lifespan, both folded into upkeep in the ledger), litter size (`litterMax`: same total energy split between the babies), kin recognition and herding (`kinDistance`, `herdBonus`: nobody attacks a relative, prey with relatives near are harder to kill; brains get relatives, comfort and water senses), disease (`diseaseTransmission`: strains target a set of genes, hosts that resemble the target catch it easily; sick organisms pay upkeep; strains are saved with the world), and camouflage (`camouflageMode`: a background color field, noticing is a fixed function of the pair and a glance period, never a random draw; hunters learn the color of their meals; `matePreference` 2 chooses mates by color). Brain inputs live in `brain.ts`: adding one shifts node numbers, so every brain-world golden changes (brains-off ones must never), and saved worlds need a renumbering rule in `restore()` (see `OLD_INPUT_COUNT`).
- Multicellularity (Phase 8), all off by default: a cell is an organism, and a colony is a group of cells joined by bonds (`bondTo`, six slots per cell, stored in both cells and kept right by `moveOrganism`/`breakBonds`). `multicellular`: a bonding gene gives the chance a baby stays attached; springs hold bonded cells near each other, bonded cells share a heading and share energy (total conserved). `cellTypes`: a bonded baby takes one of six types from three body-plan genes by how many bonds its parent has; specialists are better at one job, worse at the rest, and are sterile; a specialist with no bonds reverts to a generalist; photosynthesizers add sunlight to the ledger. `contactBonding`: a stickiness gene lets touching cells bond to strangers (symbiosis; nothing rewards it). It does not support brains yet. The bonding, body-plan and stickiness genes are left out of the kinship/species mask. Colony stats include cell types and a mirror-symmetry score.
- Phase 8b adds evolvable social genes, both optional: `kinTolerance` makes tolerance of relatives the 19th gene (the gene times `kinDistance` is the closeness at which an organism will not attack, so founders start willing to attack anyone; the cost is counted on the sensing line), and `sexualReproduction: 2` makes sex the 20th gene (each time an organism is ready it either splits in two or looks for a mate, with the gene as the chance; it waits, still eating, until it finds one; `sexMode` remembers each organism's choice). Both genes are left out of the species and compatibility masks. Finding: the selfish-herd bonus, not kin restraint, is what stops predators from forming; keep `herdBonus` small in worlds that should have a food web.
- Phase 8b also adds, all optional: weather fronts and harsh and mild years (`weatherAmplitude`, `yearVariability`; both need a climate; growth never goes negative), the fat gene (`fatDepositRate`: a separate energy reserve banked from surplus and drawn back when hungry) and torpor gene (`torporSaving`, needs a climate), kinds of plant (`plantTypes` 2 to 6: each cell grows one fixed kind in patches, the kinds peak at different times of year, and the 23rd gene, the palate, sets how well an animal digests each kind; smell and steering use digestible food), `founderSpread` (random starting values for the newer genes), and for brains: memory (`brainMemory`: four cells fed back as inputs), a sense of home (`homeMode`), and four chemical signals (`chemicals`: reward, stress, bond and calm, offered as inputs only, with no reward for having them). The brain layout grew (52 inputs, 7 outputs, 16 hidden units, 512 connections), so brain-world goldens were re-recorded; brains-off goldens never change. Colonies work with brains (each cell keeps its own brain). Phase 8c: torpor is graded (slows in proportion to the gene; a binary version never evolved), fat is a separate reserve (`fatStore`, in the energy audit and in corpses; `fatDepositRate`), `homeMode: 3` makes home the best remembered feeding place, and `chemBodyEffects` lets the stress and calm signals act on the body through two response genes. Keep new traits graded and give them an immediate small benefit, or evolution cannot find them. Also: `mutationLoadRate` (harmful mutations: bad spots in the genome that only mixing can shed) is what makes sex pay (with starting variety in the sex gene); `luckSpread` rolls two non-inherited bell-curve multipliers (upkeep and reproduction threshold) at birth, costs and gates only; `shareRate` is the generosity gene (kin-only sharing evolves only when `kinDistance` is small). Phase 8d: use `mutationLoadModel: 1` (textbook Muller's ratchet: unlimited places for harm, no mending) for anything about sex; the 24-spot model 0 saturates when selection is weak and makes sex pointless. Facultative sex (`sexWaitLimit`) and easier mates (`mateReadyFraction`) cut mate-search deaths. Lowering `mutationLoadRate` removes the reason for sex. The fat reserve holds sex back in the grand world. `configs/grand-world.json` turns on everything in a 512 world.
- Phase 8e (ecology overhaul), all optional and off by default (check the goldens after touching any of them): the births-blocked counter is split into soil / energy / both; overgrazing (`overgrazeDamage`: cells eaten bare gain damage and regrow slowly), fouling (`fouling`: crowding fouls the ground, judged against the average cell, slows plants and speeds disease), erosion (`erosionRate`: bare ground loses `soilHealth`, which scales both regrowth and the plant ceiling), and the toxicity gene (27th gene, `toxinStrength`: poison costs upkeep, poisons eaters, and hunters learn to avoid the color of a poisonous meal). New per-cell arrays are saved only when their feature is on, so older saved worlds still load. Disaster events (`ev*Every` settings, 0 = off; `eventsStep()` in `simulation.ts`): ice age, drought, meteor, wildfire, storm, flood, volcano, plant blight, outbreak and good year, several at once, each drawing its size, radius and length from a range when it starts. They use their own random stream derived from the seed (`eventRng`), so switching them on never reshuffles anything else, and the older `catastrophe*` settings still work untouched alongside them. Each says where destroyed energy and matter go (plant energy to `decayLoss`; burnt plant matter straight to soil nutrient, crushed plant matter to detritus; animals killed become corpses; a storm moves soil nutrient, it never destroys it). Floods flip `passable` and give it back at the end; volcano ash (`ash` array) raises plant growth and ceiling and fades. Fire spreads by how much plant stands in a cell compared with the average cell, because absolute thresholds do not travel between worlds.
- Phase 8e Opus batch, all optional and off by default. `nutrientMode` (O1): 1 = each animal carries a nutrient store (matter) filled by eating (a little of plants, most of meat), lost slowly as dung wherever it walks, capped by body size; babies are built from the parent's store, not the soil, and get a share of what is left; an animal short of nutrient pays extra upkeep; stores go into corpses and the matter audit (`stores`). 2 = as 1, and plants hold nutrient per unit according to the soil they grew from (`plantQ`, mixed by weight), so poor ground grows poor food. `terrainMode: 2` (O2): climate biomes. Same seas and highlands as mode 1; each land cell gets a lasting moisture (water nearness, rain belt, noise; `moistureBase`) and a biome from average temperature and moisture (tundra, boreal, grassland = plains, temperate forest = forest, desert, savanna, tropical, swamp, highlands = mountain), each with growth, move cost, how easily animals are seen and disease rate (`biome*` settings). Plant growth follows moisture; land whose average temperature (no seasons, but with drift and ice-age or volcano cooling) is below `iceBelow` is ice (`iced`, recomputed every tick, not saved). `drinking: 1`: animals carry water (`hydration`), drink beside water, in a flood or on soaked ground, and pay upkeep when dry. The brain layout grew to 63 inputs and 576 connection slots (own nutrient store, plant richness, ground damage, water direction and distance, thirst; each reads 0 when its feature is off); brain-world goldens were re-recorded, and worlds saved with the older layout are renumbered on load (`brainLayout` in the save). The disaster engine has fire scars (`fireScar`): burnt ground cannot burn again for `evFireRecover` ticks. Colony physics (O3, need `multicellular`): `colonyProtect` (hunters judge prey by the whole colony's size), `colonyScaleSaving` (each cell's upkeep falls with colony size), and `signaling` (the 28th gene, needs brains: bonded carriers share the nearest bigger animal they see and which way plants smell stronger, heard one tick late by neighbors that also carry it, as six colony senses; each bond costs `signalCost` x gene). The brain layout is now 69 inputs and 640 slots; `BRAIN_LAYOUTS` in `brain.ts` lists every layout so far, and `renumberOldNode` loads a world saved with any of them. When adding inputs, append a layout to that list.
- Sexual reproduction is a toggle (`sexualReproduction`, off by default so older worlds are unchanged): ready, nearby, genetically compatible organisms pair up and have one baby (genes and brains mixed, see `crossoverBrains` for why hidden units come from one parent), each paying half the energy.
- Saving: `Simulation.save()` and `Simulation.load()` (snapshot.ts) round-trip the whole world exactly. A guard test in `snapshot.test.ts` fails if you add a field to `Simulation` without either saving it or listing it as scratch space; do one or the other.
- Scarce food is shared by claim (see `contestStrength` in the config), which makes the result independent of the order organisms are processed in.
- In the browser the sim runs in a Web Worker and the UI stays on the main thread.
- Keep a fast-forward mode that skips rendering. Profile before optimizing.
- Hosting is static (GitHub Pages). The viewer reads `VITE_BASE` so it works under `/<repo-name>/`.
